# Analysis

Reproduces every quantitative claim in the SoftwareX article and in the
response to reviewers.

## Contents

| File | Purpose |
|---|---|
| `BahriApp_Reviewer_Response_Analysis.ipynb` | The audit. 74 cells, 18 sections, each mapped to a numbered reviewer comment. Regenerates 31 result tables and 8 figures. |
| `verify_extractor_logic.py` | Python mirror of the v1.1 Dart extractors, running the same 30 assertions as `test/feature_extractors_v11_test.dart`. Lets you check the arithmetic without a Flutter toolchain. |
| `figures/` | Figures as generated by the notebook. |

## Running the notebook

Place the eleven pilot CSVs in a `data/` folder beside the notebook:

```
analysis/
├── BahriApp_Reviewer_Response_Analysis.ipynb
└── data/
    ├── Accelerometer_Data.csv
    ├── Gyroscope_Data.csv
    ├── Handwriting_Data_Amharic.csv
    ├── Handwriting_Data_English.csv
    ├── Keystroke_Data_Amharic.csv
    ├── Keystroke_Data_English.csv
    ├── Keystroke_FreeText_Data_Amharic.csv
    ├── Keystroke_FreeText_Data_English.csv
    ├── Keystroke_PasswordText_Data.csv
    ├── Swipe_Data.csv
    └── Tap_Data.csv
```

Then:

```bash
pip install pandas numpy matplotlib jupyter
jupyter notebook BahriApp_Reviewer_Response_Analysis.ipynb
```

Runtime ≈ 2 minutes, peak memory ≈ 1.2 GB. Deterministic apart from two
fixed-seed subsamples used only for scatter plots.

## Verifying the corrected extractors

```bash
python analysis/verify_extractor_logic.py
```

Expected: `RAN 30 | failures 0 | errors 0`.

This validates the **arithmetic** of the corrected algorithms. It does not
check Dart syntax or Flutter API usage — for that, run the real suite:

```bash
flutter test test/feature_extractors_v11_test.dart
```

Both suites assert the same 30 properties, and both fail against v1.0 by
construction.
